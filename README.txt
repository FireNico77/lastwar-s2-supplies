使い方（まず試す）
1. ZIPを解凍します。
2. index.html と coordinates.json を同じフォルダに置きます。
3. 実際のスマホで使う場合は、両ファイルをHTTPS対応の静的ホスティングにアップロードしてください（例：GitHub Pages）。
4. 共有API未設定では記録は各端末のブラウザ内だけに保存されます。

連盟共有の設定
1. Googleスプレッドシートを作成し、シート名を events にします。
2. 1行目に ts,date,type,id,level,x,y,name を入力します。
3. 拡張機能 > Apps Script に Code.gs のコードを貼り付けます。
4. デプロイ > 新しいデプロイ > ウェブアプリ。実行ユーザーは自分、アクセスできるユーザーは連盟員の運用に合う設定を選びます。
5. 発行された /exec URL をアプリの共有・設定に入力します。
6. 全員が同じWebアプリURLと同じAPI URLを使います。

注意：Google Apps Scriptの公開範囲を「全員」にすると、URLを知る人がアクセスできる可能性があります。連盟外に共有しないでください。運用上のアクセス制限を確認してください。

注意：マップは座標点をプロットする簡易マップです。ゲーム内の地形画像を背景にしたものではありません。「物資なし」は報告時点の観測であり、永久に空であることを保証しません。
